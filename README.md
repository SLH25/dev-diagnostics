# Dev Diagnostics

A packaged Python command-line tool for inspecting a developer
environment and generating a deterministic health report.

## Features

- Python version check
- Disk space check
- Environment variable check
- Developer tool detection
- JSON output
- Human-readable output
- Diagnostic event analysis
- Useful exit codes
- Automated tests

## Requirements

- Python 3.10 or newer
